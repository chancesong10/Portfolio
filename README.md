# Chance Song · Portfolio

My personal portfolio site: a 3D clay turntable with one model per project (built with Three.js), followed by project write-ups, experience, skills and contact details.

**Live site:** https://chancesong10.github.io/Portfolio/

## Run locally

It's a single static page with no build step. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Files

- `index.html`: the whole site (HTML, CSS and JS)
- `Chance_Song_Resume.pdf`: résumé linked from the Skills and Contact sections
